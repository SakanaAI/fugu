Codex is now pinned to 0.172.0

Fugu now targets Codex 0.172.0. The launcher will offer to switch your Codex to it, and your existing Fugu configs, API key and endpoint carry over unchanged.

This spans seven upstream releases (0.166 through 0.172): Tab completes slash-command arguments, the workspace panel beside the conversation, with searchable document previews, image previews and subagent transcripts, is now enabled by default, the prompt composer gains undo and redo, drafts and queued follow-ups stay with their own sessions when you switch or resume, the transcript gains keyboard-driven selection with word, line and page motions and built-in search, the fullscreen transcript can collapse completed turn details beneath each prompt, Ctrl+L clears the screen while Ctrl+T still shows earlier messages, patch details can be expanded while an approval prompt is open, and codex doctor --network-only checks just your configuration and connectivity. codex exec now keeps project configuration and MCP servers disabled in untrusted directories, even with --sandbox workspace-write; pass --trust to save a project's trust. Interrupted turns also close cleanly, a delayed abort no longer interrupts a later turn, provider errors are reported as soon as they arrive, and codex exec resume restores the saved sandbox permissions and working directory.

Nothing is required on your part, and your Fugu models and settings work as before. Codex 0.167.0 added a set of task tools to every interactive session, including tools that create and list git worktrees, which the earlier [mcp_servers.codex_worktrees] entry no longer keeps out. ~/.codex/fugu.config.toml now carries a disabled placeholder entry named [mcp_servers.codex_tui] in its place, so Fugu sessions stay without those tools as before; it is never started, and removing that table by hand lasts only until the next update replaces the file.
