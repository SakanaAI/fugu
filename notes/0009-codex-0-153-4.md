Codex is now pinned to 0.153.4

Fugu now targets Codex 0.153.4. The launcher will offer to switch your Codex to it, and your existing Fugu configs and API key carry over unchanged.

This spans several upstream releases (0.150 through 0.153): it adds task @-mentions and terminal tools for creating, reading, and managing Codex tasks, a /copy picker for full responses or individual code blocks, automatic descriptive titles for unnamed tasks with /rename suggestions, clickable Markdown links, keybindings to cycle permission modes, richer Vim editing (search, undo/redo, and dot-repeat), Interrupt hooks that run commands or MCP handlers when a turn is interrupted, extensions that can inspect or replace MCP tool results, a plugin CLI that lists, installs, and removes plugins from remote marketplaces, rate-limit banners with usage and plan actions, and credential-refresh progress in the terminal. None of that changes how Fugu works — you reach the same Fugu models through the same Sakana API, with the same stream-resilience and safety settings as before.

Nothing is required on your part, and Fugu behaves the same as before. The Fugu config still pins remote plugins off ("remote_plugin = false" in the [features] block of ~/.codex/fugu.config.toml) and Codex 0.148.0's unbounded connection retries off ("unbounded_connection_retries = false") so a down or misconfigured endpoint fails with a bounded, reported error instead of retrying forever; remove either line to opt back into upstream's defaults.
