Codex is now pinned to 0.154.0

Fugu now targets Codex 0.154.0. The launcher will offer to switch your Codex to it, and your existing Fugu configs and API key carry over unchanged.

Upstream adds experimental worktree support for isolated checkouts (--worktree and /worktree), the ability to answer questions inline while Codex keeps working, a background Codex server on Windows, an R replace mode in the Vim composer with more reliable Escape handling, and richer /copy behaviour that preserves formatting and can copy status output or individual session fields. It also fixes plugin tool and skill refreshes in existing sessions, coordinates MCP OAuth token refreshes, preserves saved permissions across remote resume and fork, and shows a read-only transcript when you resume a conversation that is open elsewhere. The deprecated "codex mcp-server" entry point has been removed; the Fugu launcher never used it.

Nothing is required on your part, and Fugu behaves the same as before. The Fugu config still pins remote plugins off ("remote_plugin = false" in the [features] block of ~/.codex/fugu.config.toml) and unbounded connection retries off ("unbounded_connection_retries = false") so a down or misconfigured endpoint fails with a bounded, reported error instead of retrying forever; remove either line to opt back into upstream's defaults.
